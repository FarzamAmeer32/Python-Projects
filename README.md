# Python Projects: Calculator & To-Do List App

This project contains two Python applications:

1. Console-based Calculator
2. Object-Oriented To-Do List Application

---

## 🧮 Calculator

A simple command-line calculator that performs basic and advanced arithmetic operations.

### Features:
- Addition, Subtraction, Multiplication
- Division, Floor Division
- Power and Modulus
- Input validation and error handling
- Continuous calculation loop

---

## ✅ To-Do List App

A console-based task management system built using Object-Oriented Programming (OOP).

### Features:
- Add tasks
- Remove tasks
- View all tasks
- Mark tasks as completed
- View completed tasks
- View incomplete tasks
- Interactive menu dashboard

---

## 🛠️ Technologies Used

- Python 3.14
- Object-Oriented Programming (OOP)
- Exception Handling
- File structure (modular code)

---

## 📁 Project Structure
-calculator.py → Calculator logic
-todo.py → To-Do list class
-main.py → Entry point (runs program)


---

## ▶️ How to Run

Run the main file:

-python main.py

## Or run individual modules:

-python calculator.py
-python to_do_app.py
